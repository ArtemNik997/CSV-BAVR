# CSV-driven Browser Automation Video Recorder

Инструмент на Python и Playwright, который для каждой строки входного CSV записывает видео автоматизированных действий в браузере: открывает DuckDuckGo, плавно ведёт курсор к полю поиска, посимвольно вводит запрос Magento developer in <city>, нажимает поиск и кликает по первому результату. В видео добавлены SVG-курсор, жёлтая подсветка, ripple при кликах и callout с текстом.

## Требования

- Python 3.9+
- Playwright для Python (sync API), браузер Chromium
- Flask и requests (для веб-сервиса и загрузки видео)

## Установка

pip install -r requirements.txt
python -m playwright install chromium

## Запуск

python capture_video.py
python capture_video.py --csv input.csv --out ./video

Для каждой строки CSV скрипт печатает путь к сохранённому видео: [1] Saved: <путь>. Видео сохраняются в ./video под именем <Company Name>.webm.

## Формат input.csv

Кодировка UTF-8, разделитель ;, ограничитель полей ". Заголовок:

URL;Company Name;Language;Country;Postcode;City;Street;HouseNo

В запросе используется значение City.

## Структура проекта

| Файл             | Назначение                                                                                   |
| ---------------- | -------------------------------------------------------------------------------------------- |
| capture_video.py | Читает CSV и для каждой строки вызывает qscript.CaptureVideo_Magento(...)                    |
| qscript.py       | Функция CaptureVideo_Magento, глобальная переменная PATH_TO_VIDEO_FOLDER, визуальные эффекты |
| requirements.txt | Зависимости                                                                                  |
| input.csv        | Пример входных данных                                                                        |
| web_service.py   | Flask-сервис и работа с SQLite: /upload, /get_video_url, /media, /videos                     |
| video_client.py  | Клиент сервиса: UploadVideo и GetVideoURL                                                    |

Функция CaptureVideo_Magento возвращает абсолютный путь к .webm или None при сбое.

## Настройки через переменные окружения

Все необязательны.

| Переменная                           | Значение                                                   |
| ------------------------------------ | ---------------------------------------------------------- |
| QS_HEADLESS=1                        | Запуск без окна браузера (по умолчанию окно видно)         |
| QS_BROWSER_CHANNEL=chrome или msedge | Использовать установленный Chrome или Edge вместо Chromium |
| QS_DEBUG=1                           | При сбое сохранять скриншот и видео неудачной записи       |

Пример для PowerShell:

$env:QS_HEADLESS="1"
python capture_video.py

## Примечания

- По умолчанию браузер открывается с окном. Для сервера или компьютера без графической среды используйте QS_HEADLESS=1 или xvfb-run -a python capture_video.py на Linux.
- DuckDuckGo может блокировать автоматические запросы (страница ошибки 418), особенно в режиме без окна или при частых запусках. В этом случае подождите, смените сеть или запустите с видимым окном.
- Скрипт рассчитан на текущие селекторы DuckDuckGo, они заданы константами в начале qscript.py.
- Если DuckDuckGo показывает страницу ошибки, qscript.py перезагружает страницу до двух раз, затем переходит к следующей строке.

## Веб-сервис для видео (Task 2)

Flask-сервис принимает записанные видео, сохраняет их в `uploads/` и хранит в SQLite (`videos.db`) название компании, путь к файлу и URL. Рекордер может загружать каждое видео на сервис и сразу открывать его в браузере.

### Установка и запуск сервиса

pip install -r requirements.txt
python web_service.py

Сервис слушает `http://127.0.0.1:8000`. `videos.db` и `uploads/` создаются автоматически при первом запуске. Адрес и порт меняются переменными `FLASK_HOST` (по умолчанию `0.0.0.0`) и `FLASK_PORT` (по умолчанию `8000`).

### Эндпоинты

| Метод и путь                               | Назначение                                                                                 |
| ------------------------------------------ | ------------------------------------------------------------------------------------------ |
| POST /upload                               | multipart-форма: `file` и `company_name`. Ответ: `{"company_name": ..., "video_url": ...}` |
| GET /get_video_url?company_name=<название> | Ответ: `{"company_name": ..., "video_url": ...}`, 404 если компании нет                    |
| GET /media/<имя файла>                     | Отдаёт видеофайл (поддерживает перемотку)                                                  |
| GET /videos                                | Список всех записей в БД (для отладки)                                                     |

Повторная загрузка той же компании обновляет запись и файл, дубликаты не создаются.

Пример:

curl -F "file=@video/Beta Solutions.webm" -F "company_name=Beta Solutions" http://127.0.0.1:8000/upload
curl "http://127.0.0.1:8000/get_video_url?company_name=Beta%20Solutions"

### Клиент (video_client.py)

| Функция                                   | Назначение                                                             |
| ----------------------------------------- | ---------------------------------------------------------------------- |
| UploadVideo(server_url, video_path, name) | Загружает видео на сервис и возвращает его URL                         |
| GetVideoURL(server_url, company_name)     | Возвращает URL видео компании, выбрасывает LookupError если не найдено |

### Запуск рекордера с загрузкой и предпросмотром

Сначала запустите сервис, затем в другом терминале:

python capture_video.py --server http://127.0.0.1:8000 --view-seconds 5

| Опция            | Значение                                                                                                  |
| ---------------- | --------------------------------------------------------------------------------------------------------- |
| --server URL     | Адрес сервиса. Если задан, после записи каждое видео загружается и открывается в Chromium                 |
| --view-seconds N | N > 0: держать браузер открытым N секунд, затем закрыть. 0: до нажатия Enter в терминале. По умолчанию 10 |

Без `--server` рекордер работает как раньше, сервис не нужен. Ошибка записи, загрузки или предпросмотра не останавливает обработку: она выводится в лог, и скрипт переходит к следующей строке. Окно предпросмотра всегда открывается с видимым окном (`headless=False`).
